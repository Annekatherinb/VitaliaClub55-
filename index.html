Configuración inicial de Firebase
Necesitas crear un proyecto Firebase gratuito:
  1. Ve a console.firebase.google.com
  2. Crea un proyecto → "vitalia-app"
  3. Habilita Authentication → Email/Password
  4. Crea Firestore Database (modo test)
  5. Ve a Configuración del proyecto → Tus apps → Web → copia el config

La configuración se guardará en tu navegador. Nadie más puede verla.
